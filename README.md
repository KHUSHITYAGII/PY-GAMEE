# Autism-Friendly Interactive Learning Game

## Project Overview
This Pygame application is specially designed to provide a supportive, engaging, and therapeutic interactive experience for individuals with autism spectrum disorder (ASD). The game focuses on creating a calm, predictable, and customizable environment that supports learning, skill development, and sensory-friendly interaction.

## Key Features
- Sensory-friendly color palette
- Customizable difficulty levels
- Low-stimulus design
- Clear, predictable game mechanics
- Adjustable sound and visual settings
- Positive reinforcement system

## Accessibility Considerations
- Minimal sudden movements or loud sounds
- Option to adjust visual and audio stimuli
- Simple, intuitive user interface
- Consistent color schemes
- Reduced cognitive load
- Customizable interaction modes

## Installation

### Prerequisites
- Python 3.8+
- Pygame library
- Additional accessibility libraries

### Setup
```bash
git clone [repository-url]
cd [project-directory]
pip install -r requirements.txt
python main.py
```
